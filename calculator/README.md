# Calculator

Simple calculator web app.

Description
- A basic calculator built with HTML, CSS, and JavaScript.
- Supports addition, subtraction, multiplication, and division with operator precedence.

How to use
- Open `index.html` in the `calculator` folder in your browser.
- Click number and operator buttons to build an expression.
- Buttons:
  - `AC` : Clear all
  - `DEL`: Delete last character
  - `=`  : Evaluate expression
  - `+`, `-`, `X`, `/` : Operators

Behavior / features
- Prevents consecutive operators (replaces previous operator if a new one is typed).
- Evaluates multiplication and division before addition and subtraction.
- Shows the full expression on the main display and a secondary display with the expression details.

Notes
- Entered expression is evaluated client-side; invalid expressions show `Error`.

Access / Hosted
- You can also open the project from the root `index.html` (top-level) which links to this calculator.
