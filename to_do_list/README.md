# To-Do List

Simple to-do list web app.

Description
- A minimal task manager built with HTML, CSS, and JavaScript.
- Add tasks, mark them complete, and delete tasks.

How to use
- Open `index.html` in the `to_do_list` folder in your browser.
- Type a task in the input and press the `Add` button or `Enter` to create a task.
- Use the checkbox to mark a task as completed.
- Click the `X` button to delete a task.

Display
- Shows counters for total tasks and completed tasks.

Notes
- Tasks are stored only in-memory; refreshing the page clears the list.

Access / Hosted
- You can also open the project from the root `index.html` (top-level) which links to this to-do app.
- The workspace is published on GitHub Pages: https://chinthaka-madushan.github.io/mini-projects/
- Input validation prevents empty tasks (alerts the user).
